## 一、为什么会有 SmewAI

这两年，越来越多人开始接触主流的 AI 编程工具，比如：

- OpenAI 的 `Codex`
- OpenAI 的 `GPT` 系列模型

它们的能力不限于聊天，还能直接接入你的工作流程，帮你处理代码、文档、信息整理、重复任务等工作。

但对很多中文用户来说，真正的问题不是“这些工具强不强”，而是：

**知道它们的人很多，能稳定用起来的人并不多。**

常见难点包括：

- 网络环境复杂
- 支付和订阅门槛高
- 配置步骤多
- API 按量计费，成本不容易预估

所以，很多人并不是不想用，而是：

**想用，但不想为了用它付出太高的学习成本、时间成本和风险成本。**

SmewAI，就是为了解决这个问题而出现的。

## 二、这些工具到底是什么

### 2.1 OpenAI 是什么

目前在 AI 编程工具领域，OpenAI 是最具代表性的公司之一。本文涉及的主要工具也围绕 OpenAI 的 GPT / Codex 能力展开。

### 2.2 ChatGPT 是什么

`ChatGPT` 是大多数人最熟悉的产品形态，也就是网页上那个可以直接聊天的对话框。

### 2.3 Codex 是什么

ChatGPT 的网页版主要以对话为主，而 `Codex` 则是：

**能在电脑终端里帮你干活的 AI 助手。**

它不只是回答问题，而是可以更深入地参与工作，比如：

- 看代码、改文件
- 帮你分析报错
- 总结文档、整理资料
- 协助处理重复性的电脑操作

所以它和网页版 AI 的核心区别在于：

**它能直接操作本地文件和终端环境，是“工作助手”而不只是“问答助手”。**

## 三、什么是终端

**终端**，你可以把它理解成：**电脑里一个专门用来输入命令的窗口。**

为什么要讲终端？因为：

**Codex 就是运行在终端里的工具。**

### 如何打开终端

**Windows**

- 按 `Win` 键，输入 `Terminal`
- 或输入 `PowerShell`
- 或按 `Win + R` 输入 `cmd`

**Mac**

- 按 `Command + 空格`，输入 `Terminal`
- 或在 `应用程序 -> 实用工具` 中打开 `终端`

## 四、这些工具运行在哪儿

**本地电脑 \+ 云端 AI 大脑。**

- `你的电脑`：负责打开终端、输入命令、显示结果
- `云端模型`：负责真正的理解、分析和生成内容

---

## 五、什么是 API

API 在这里可以理解为：**让你的电脑程序去调用 AI 大脑的通道。**

像 `Codex` 这类终端工具，本质上也是通过 API，把你的请求发给模型，再把结果返回给你。

## 六、为什么很多人知道这些工具，却还是用不好

### 6.1 官方方案不一定适合所有人

不同官方产品和套餐的费用差异较大；对不少用户来说，真正的门槛不只是价格，还包括网络环境、支付方式和配置复杂度。

### 6.2 API 方案虽然灵活，但成本容易失控

如果没有一个清晰的网关、模型分组和消费视图，新手往往在还没掌握用法时就已经产生较高费用。

---

## 七、SmewAI 是什么

SmewAI 的定位是：

**帮助用户以更低的门槛和更稳定的方式使用 GPT / Codex 这类模型能力的方案。**

它要解决的问题：

- 怎么降低使用门槛
- 怎么减少网络和支付折腾
- 怎么让新人也能开始用终端工具
- 怎么让成本更可控
- 怎么让 Windows 和 Mac 用户都更容易上手

> **一句话总结：SmewAI 是一个帮助普通用户低门槛使用主流 GPT 编码工具的解决方案。**

## 八、遇到报错怎么办一步步排查

在安装和使用过程中，遇到看不懂的报错很正常。建议遵循一个原则：

**一次只解决一个问题，一步一步来，不要偏离目标。**

排查时建议提供：

1. 你当前的目标是什么
2. 你刚刚执行了什么命令
3. 终端的完整报错原文
4. 你当前系统是 Windows、macOS 还是 Linux

如果可以截图，把终端完整截图附上，通常比手工摘录更准确。

## 十、安装配置工具

### 第 1 步：安装 Node.js

请先参考 [Node.js 环境安装指南](nodejs-setup)。

### 第 2 步：创建 API Key

进入 [SmewAI 控制台](https://smew.ai/keys) 创建 API Key，选择 GPT / Codex 对应分组。

### 第 3 步：安装 Codex

```bash
npm install -g @openai/codex@latest
```

### 第 4 步：配置 Codex

你可以选择手动配置，或直接使用 [自动配置工具](auto-config-tool)。

### 第 5 步：验证可用性

```bash
codex --version
codex
```

如有报错，按[第八节的方法](#八遇到报错怎么办一步步排查)逐步排查。

## 十一、入门使用手册

### 11.1 怎么启动 Codex

进入你的项目目录，运行：

```bash
codex
```

### 11.2 第一次可以问什么

进入 `Codex` 后，可以先试这些问题：

- `请概括一下当前项目结构。`
- `请解释这个仓库的启动方式。`
- `请帮我找出这个报错最可能的原因。`
- `请先给我一个修改计划，不要直接改代码。`

### 11.3 新手建议

- 优先从小任务开始
- 遇到报错先贴完整输出
- 复杂任务先让它给计划，再决定是否执行
- 每完成一轮改动，记得查看 diff 和测试结果
