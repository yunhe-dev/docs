# SmewAI 使用指南

欢迎使用 SmewAI —— 面向中文开发者的 AI 编码与图片生成接入平台。

---

## 什么是 SmewAI？

SmewAI 将 **Codex** 与 **GPT-Image** 等能力接入同一条稳定线路，提供统一的配置方式、计费视图与使用体验。

### 核心功能

- **统一接入**：一个 API 地址，覆盖 Codex 与图片生成能力
- **透明计费**：每一次调用成本清晰可查
- **多平台支持**：Windows / macOS / Linux 全覆盖
- **团队协作**：支持多用户、分组与订阅管理

## 快速开始

### 1. 注册账号

访问 [SmewAI 官网](https://smew.ai/register) 完成注册。

### 2. 创建 API Key

登录后进入「API Keys」页面，创建一个新的 API Key。

### 3. 配置你的开发工具

将获取到的 API Key 和网关地址填入你的 IDE、CLI 或图片工具中。详细教程请参考左侧导航中的各平台使用指南。

如有任何问题，请通过控制台中的联系方式联系客服。
